## 2. Kontrakt numeryczny

Kształty: `C, delta_E, S: (N,)`, query pojedynczy.  
Batch później: `(B, N)` — nie w v1, chyba że nic nie psuje testów.

- `C >= 0`. Jeśli `mask`: `C = C * mask`, `support = mask > 0`.
- `sum(C[support]) > 0` inaczej `raise ValueError`.
- `gamma = gamma0 * (1 + beta * kappa)`, `gamma0 > 0`, `beta >= 0`.
- BW: `W_tilde = gamma * C / (gamma**2 + delta_E**2)`, `W = W_tilde / W_tilde.sum()`.
- Relaksacja: `S = (1-rho)*S + rho*W`, renormalizacja do simplexu (dryf fp).
- `kappa="max"`: `S.max()` — default eksperymentu (zgodne z notatką).
- `kappa="lse"`: `tau * logsumexp(S/tau)` z `tau=0.05` — tylko ablacjа, flaga.

Floor: `gamma0 = max(gamma0, 1e-8)`. Nie clampować `gamma` do zera.

`delta_E` nie zależy od `S` wewnątrz `tsra_relax`.

### PR3 — metryki
Dla trajektorii i finału:
- `H = -sum(S*log(S+eps))`
- `kappa = max(S)`
- `dS = ||S[t]-S[t-1]||_1`
- `steps_to_eps` (pierwsze `t` z `dS < eps`)
- `oscillating`: po `t > t_burn` znak `kappa[t]-kappa[t-1]` zmienia się ≥ `n_flips` albo period-2: `||S[t]-S[t-2]|| < eps` i `||S[t]-S[t-1]|| > eps`
- `diverged`: `K==Kmax` i `dS >= eps` i nie period-2
- `converged`: `dS < eps`

Klasyfikacja punktu siatki (po wielu startach):
`converged | oscillate | mixed | diverged`  
`mixed` = różne starty, różne klasy.

### PR4 — reżimy syntetyczne

`S0 ~ Dirichlet(ones)` — 100 startów.

`N` default 32. Parametry `scale` w CLI.

### PR5 — jacobian (finite diff)
- W `S*` (po konwergencji), komora stałego `argmax` (nie przechodzić przez ścianę).
- `J = (1-rho)*I + rho * dW/dS`
- `dW/dS` kolumnami: perturbacja `e_k`, projekcja z powrotem na simplex (`S' = (S+h e_k)_+ / sum`) albo perturbacja w hiperpłaszczyźnie `sum=0`.
- `spectral_radius = max|eig(J)|`
- Jeśli `kappa=max` i perturbacja zmienia `argmax` — oznacz `unreliable=True`, nie używaj do linii \(\rho(J)=1\).
